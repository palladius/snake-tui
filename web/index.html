Come funziona il Bridge TUI → Web (senza riscrivere il gioco):
1️⃣ Modalità Static Ruby WASM (100% Client-Side / GitHub Pages): Il browser carica @xterm/xterm (emulatore ANSI) + @ruby/3.3-wasm-wasi (CRuby 3.3 compilato in WebAssembly), scarica con fetch() i file originali lib/snake_tui/food.rb, game.rb e renderer.rb, e chiama renderer.render_to_string(game) iniettando le sequenze ANSI direttamente nel terminale web.
2️⃣ Modalità PTY WebSocket (./bin/snake-tui-web): Un micro-server Ruby di 90 righe usa PTY.spawn("./bin/snake-tui") per creare uno pseudo-terminale Linux reale e trasmette i byte ANSI via WebSocket a xterm.js.
